# 02 — Architecture, SDK & Memory Budget

## Repository Structure

- [`cmd/lmgcp/main.go`](../cmd/lmgcp/main.go): CLI entrypoint handling `--version`, `--help`, `--notices`, `--dsl-schema [--json]`, `--dsl-signatures [--without-std]`, `--dsl [--dry-run] FILE...`, and `--sweep [--older-than-hours N] [--delete]`. Embeds `cmd/lmgcp/VERSION` and `THIRD_PARTY_NOTICES`.
- [`internal/membudget/membudget.go`](../internal/membudget/membudget.go): `LMGCP_MAX_MEMORY_MB` parser, byte charge tracker, Go runtime memory limit, and 2ms heap watchdog.
- [`internal/safety/safety.go`](../internal/safety/safety.go) & [`safety_test.go`](../internal/safety/safety_test.go): Secret redaction, project ID masking, prefix/shape/tier allowlists, `RunLedger` ownership, and `us-central1` cost price table.
- [`internal/fakegcp/seed.go`](../internal/fakegcp/seed.go) & [`server.go`](../internal/fakegcp/server.go): Deterministic in-process HTTP REST server emulating 16 Google Cloud service domains pre-seeded with 43 baseline resources across `prod-vpc`, `staging-vpc`, and `analytics-vpc`.
- [`internal/host/`](../internal/host/): `Host` implementation (`host.go`, `types.go`, `collections.go`, `register.go`, `host_test.go`) wrapping Google Cloud Go SDK clients and registering all DSL types, methods, and functions on `lmcode.Registry`.
- [`schema/lmgcp.dsl.json`](../schema/lmgcp.dsl.json) & [`schema/schema.go`](../schema/schema.go): Embedded host JSON schema generated by [`scripts/gen-schema.py`](../scripts/gen-schema.py).
- [`compare/`](../compare/): 40 OpenTofu (`lmcloud`) equivalents (`compare/<example>/main.tf` + `<example>.lms`), [`compare/run.sh`](../compare/run.sh), [`compare/gen_results.py`](../compare/gen_results.py), and [`compare/RESULTS.md`](../compare/RESULTS.md).

## Memory Budget Contract (`LMGCP_MAX_MEMORY_MB`)

- **Default budget**: `4096` MiB (`membudget.DefaultBudgetMiB`).
- **Invalid configuration (exit `2`)**: Setting `LMGCP_MAX_MEMORY_MB` to an empty string, `<= 0`, non-integer, or `> 1048576` prints an error naming `LMGCP_MAX_MEMORY_MB` to `stderr` and exits with code `2` before host initialization.
- **Runtime enforcement (exit `3`)**:
  - Host methods (including `gcp.alloc_scratch_mb(mb)`) charge allocations via `membudget.Charge(bytes)` and check `runtime.ReadMemStats` heap deltas against the budget.
  - During `prog.Run(ctx, reg)`, `membudget.StartWatchdog` polls `CheckRuntime()` every 2ms so runaway VM allocations are caught immediately.
  - On budget breach, `lmgcp` runs `h.CleanupLedger()`, writes the error naming `LMGCP_MAX_MEMORY_MB` to `stderr`, writes the structured `{"ok":false,"stage":"run","code":"RUN_HOST",...}` JSON error to `stdout`, and exits with code `3`.
